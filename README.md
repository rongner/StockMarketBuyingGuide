# Stock Market Buying Guide

A full-stack portfolio project that uses AI to recommend 5 stocks to buy each day, with historical backtesting and multi-day portfolio simulation. Built as a demonstration of modern web technologies across the full stack.

---

## Features

### AI & Data
- **AI stock picks** — daily recommendations generated by LLaMA 3.3 70B via the Groq API using OpenAI-compatible tool calling (function calling) for structured output
- **Real-time market data** — live quotes and historical OHLCV data via the Yahoo Finance v8 chart API
- **News integration** — financial news fetched from NewsAPI and fed into the AI prompt as context
- **Historical backtesting** — run the AI recommendation engine against any past date and compare picks to actual market outcomes (1-day, 5-day, 20-day returns)
- **Portfolio simulation** — simulate a multi-day trading strategy over a date range, tracking capital changes day by day with a background job queue

### Backend (.NET 10)
- **ASP.NET Core Web API** with controller-based routing and `ProblemDetails` (RFC 7807) error responses
- **Google OAuth + JWT** — server-side Google ID token validation via `Google.Apis.Auth`, issuing HS256 JWTs for subsequent requests
- **Entity Framework Core** with Npgsql (PostgreSQL), EF migrations, and a service layer architecture
- **Background processing** — `IHostedService` + `Channel<T>` for a non-blocking simulation job queue; the controller returns a job ID immediately and the client polls for completion
- **Rate limiting** — fixed window rate limiter (`Microsoft.AspNetCore.RateLimiting`) on mutating endpoints
- **Structured logging** — Serilog with console and daily rolling file sinks; frontend log entries forwarded to the API and written through the same pipeline
- **CORS** — origins loaded from configuration

### Frontend (React + TypeScript)
- **React 19** with TypeScript and Vite
- **TanStack Query** for data fetching, caching, and background polling
- **React Router v7** with protected routes and an auth context
- **Google OAuth popup** via `@react-oauth/google`
- **Recharts** area charts for portfolio simulation visualisation
- **Tailwind CSS v4**
- **Axios interceptors** — automatic JWT attachment and 401 redirect
- **Pluggable frontend logger** — `ConsoleTransport` locally, `ApiTransport` to batch and ship logs to the backend

### DevOps & Tooling
- **Docker** — multi-stage builds for both the API (`dotnet/sdk` → `dotnet/aspnet`) and the web frontend (`node` → `nginx`)
- **GitHub Actions** — parallel CI jobs that build and push both images to GitHub Container Registry (`ghcr.io`) on every push to `main`, with GitHub Actions layer caching
- **Branch protection** — `main` requires passing CI and a pull request; direct pushes are blocked
- **CODEOWNERS** — default reviewer assignment on all PRs
- **PR template** — consistent pull request structure

## Running Locally

### Prerequisites
- .NET 10 SDK
- Node.js 22+
- PostgreSQL 17
- A [Groq API key](https://console.groq.com) (free)
- A [NewsAPI key](https://newsapi.org) (free tier)
- A Google OAuth client ID

### API

```bash
cd src/StockMarketBuyingGuide.Api
# Fill in appsettings.Development.json with your keys and connection string
dotnet run
```

### Web

```bash
cd src/StockMarketBuyingGuide.Web
npm install
npm run dev
```

### Database

```bash
cd src/StockMarketBuyingGuide.Api
dotnet ef database update
```
